# Security

Colligo handles paths, URLs and credentials of restricted studies. Please report a vulnerability privately, never in a public issue.

## Reporting

Use GitHub's private vulnerability reporting: the "Report a vulnerability" button under the Security tab of this repository. Include the version, what you observed, and how to reproduce it with synthetic data.

Never attach real patient, restricted or controlled-access data to a report, not even a file name.

## Scope

In scope: anything that lets a path, URL or credential of a restricted study leave Colligo (logs, errors, reports, certificates, manifests), and anything that makes Colligo report data as verified when it was not.
